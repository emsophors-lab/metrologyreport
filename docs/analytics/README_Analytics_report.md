# Smart Analytics report – official template (Khmer)

| File | Where it goes in the project |
|---|---|
| `Analytics_template_v1.docx` | `public/templates/Analytics_template_v1.docx` |
| `analytics-sample-data.json` | `src/lib/analytics/__fixtures__/` (data contract: every key the template needs) |
| `Analytics_sample_filled.docx` | `docs/analytics/` (expected output for the sample data) |

The same period tags as the consolidated report are used (`period_word_kh`, `period_label_kh`, `period_range_kh`, `chk_*`), so this one template works for monthly, quarterly, semester and annual reports.

## Tags
- **Memo:**
  - Header and period: `letter_no` `period_label_kh` `annex8_months_kh`
  - Figures: `licensees_analyzed_kh` `records_analyzed_kh` `overall_risk_kh`
  - Findings: `key_findings[].text` (paragraph loop)
  - Signature block: `lunar_date_line` `signed_day_kh` `signed_month_kh` `signed_year_kh` `head_name`
- **Title:** `chk_month` `chk_quarter` `chk_semester` `chk_year` `period_range_kh` `report_no` `generated_at_kh` `model_set_version`
- **1. Executive summary:** `executive_summary`, plus loop `kpis` (`no` `name` `current` `previous` `trend`)
- **2.1 Data analysed:** `data_period_kh` `licensees_analyzed` `records_analyzed` `data_completeness` `records_excluded` `records_no_gps` `data_as_of_kh`
- **2.2 Models:** loop `models` (`no` `name` `purpose` `method` `performance` `version`)
- **3. Trends and forecast:** loop `forecasts` (`no` `category` `previous` `current` `forecast` `interval` `trend`), plus `trend_commentary`
- **4. Licensee risk:** `risk_high` `risk_medium` `risk_low` `risk_total`, plus loop `high_risk` (`no` `licensee` `licence_no` `score` `previous_score` `factors` `action`)
- **5. Anomalies:** loop `anomalies` (`no` `type` `subject` `description` `score` `review_status`)
- **6. Geographic analysis:** loop `geo` (`no` `province` `installed` `repairs` `fail_rate` `risk_level` `remark`), plus `geo_commentary`
- **7. Instrument quality:** loop `quality` (`no` `model` `manufacturer` `verified` `failed` `fail_rate` `remark`), plus `min_sample`
- **8. Recommendations:** loop `recommendations` (`no` `priority` `text` `responsible` `timeline`)
- **9. Limitations:** loop `limitations[].text` (paragraph loop)
- **10. Conclusion:** `conclusion`
- **Annex 1:** loop `all_risk` (`no` `licensee` `licence_no` `score` `level` `change` `factors`)
- **Analyst and reviewer:** `analyst_name` `analyst_position` `analysed_date_kh` `reviewer_name` `reviewer_position` `reviewed_date_kh`

**Fixed text (no tags):** Section 9 (human oversight) and the Annex 2 glossary are part of the template on purpose; the system does not fill them.

## The machine is the analyst

NMC's decision: nobody types the analysis. The models do it, the AI agent
words it, and the report is signed by the engine that produced it.

| Tag | Filled by | Notes |
| --- | --- | --- |
| `analyst_name` | the system | Names the model set, e.g. `ប្រព័ន្ធវិភាគស្វ័យប្រវត្តិ MLRS-AI v1.2 (AI Agent)`. The version is there so the figures can be reproduced. |
| `analyst_position` | the system | `ម៉ូដែលរៀនដោយម៉ាស៊ីន (ML) និងភ្នាក់ងារបញ្ញាសិប្បនិម្មិត (AI)` |
| `analysed_date_kh` | the system | The date the analysis ran, Khmer numerals. |
| `reviewer_name`, `reviewer_position`, `reviewed_date_kh` | an officer | Still required. Approval refuses without a named reviewer. |

A request cannot overwrite the first three — `applyTextInputs` drops them —
so a client cannot put a person's name on the machine's work.

`head_name` is no longer a tag: the department head is printed in the Word
template itself (owner's updated file, SHA-256 `2c99e809…`).

### Where machine learning enters

With `ML_LIFECYCLE_ENABLED=true` and a trained model active:

- **Risk scores.** The rule score stays the floor. A classifier probability
  of 0.5 or more adds up to 20 points on top, and arrives with a factor
  naming the probability and the feature that departed furthest. The model
  escalates and never discounts — the rules are the part NMC can defend to a
  licensee.
- **Anomalies.** IsolationForest outliers appear as review signals, limited
  to licensees who filed in the period, each naming the feature behind it.
  All start at `រង់ចាំពិនិត្យ`.
- **Model table.** The trained classifier, IsolationForest and k-means rows
  report F1, accuracy and silhouette as measured on held-out data, or
  `មិនទាន់វាស់`.

With no trained model the report says so in its limitations rather than
presenting rule scores as machine learning.

### Where the AI agent enters

With `ANALYTICS_AI_ENABLED=true` and `GEMINI_API_KEY` set, the agent writes
`executive_summary`, `trend_commentary`, `geo_commentary` and `conclusion`.
Four things are enforced in code, not asked for in the prompt:

1. **No invented figures.** Every digit group in the agent's text must
   already appear in the figures we sent. A sentence rounding 96.4% to "about
   96%" is rejected and the deterministic draft used instead.
2. **No licensee is named to it.** The payload is built by naming what goes
   in — counts, rates, provinces, period labels — so a tag added later cannot
   leak. No company name, licence number, serial or address leaves the
   server.
3. **It decides nothing.** Scores, review statuses, priorities and every
   figure come from the models and the rules.
4. **Failure is not an error.** No key, no network, a bad answer or a
   timeout: the deterministic drafter produces the report, and the
   limitations list says which wording it carries.

An officer may still correct any sentence, and a correction wins.

Checks: `npm run analytics:check` (template contract, statistics, rendering)
and `npm run analytics:ai:check` (the four guards above, the ML contribution,
and the no-key path).
